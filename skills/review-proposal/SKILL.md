# Review a proposal

1. Read the job post first. List what the client asks for: tasks, tools, instructions for applicants.
2. Check the first two lines of the cover letter. They must speak to the client's problem, not to the freelancer's credentials.
3. Check every client instruction (for example a word to start with). A missed instruction is the first issue.
4. Check each claim against the facts about the freelancer. Remove or flag any claim with no source.
5. Check that every screening question has a real, specific answer.
6. Fix mechanical problems last: length, spacing, dashes, rate range.
7. In the fixed version change only what is needed. Keep the freelancer's voice.
