# Check keyword rank

- Rank is the place of the freelancer's profile in the freelancer search for one keyword. Lower is better.
- Only read tools are used. The search is paged; stop after the configured number of pages and report "not found" instead of guessing.
- Compare a 7-day average, never a single day. Search results move from day to day.
- A rank change right after a profile change is not proof. Wait for the test period before judging.
- Never change the keyword list without the owner's approval.
