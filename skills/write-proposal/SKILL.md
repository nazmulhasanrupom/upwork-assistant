# Write a proposal

1. Read the job post and the plan. List the client's problem, tasks, tools and instructions for applicants.
2. Open with the client's problem in their own terms. No greeting filler, no list of credentials first.
3. Follow every client instruction (for example a word to start with) inside the letter.
4. Use one real proof from the facts about the freelancer, stated exactly as the facts state it. Never invent clients, numbers or results.
5. Answer each screening question with specific content. If the facts do not cover it, say honestly what the freelancer would do.
6. Keep it short and plain. No markdown, emoji, links, em dashes or en dashes.
