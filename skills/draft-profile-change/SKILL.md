# Draft a profile change

1. Change one field and one idea only, so the result of the test can be read.
2. Use only facts about the freelancer. Never invent skills, tools, clients or numbers.
3. Put the main keyword near the start of the title and in the first two lines of the overview.
4. Open the overview with the result the client gets, then the credentials.
5. Never copy words from other freelancers' profiles.
6. Respect the field limits; a text over the limit is refused, not cut.
7. Plain words, no hype, no markup, no em dashes.
