How to log in from your own computer

The Upwork login lives in Claude Code, inside this app's container. Do this once on your own computer, and again if the login expires:

  1. Install Claude Code, then run these commands in a terminal: 
    {{ login_commands }}
  2. In Claude, type /mcp, choose upwork, choose Authenticate, and log in to Upwork in the browser. Then type /exit.
  3. Upload $HOME/upwork-claude-test/.credentials.json here, in the "Import Claude login" box below.
  4. Press Test connection.

That file holds a login token. After the import you can delete it from your computer (and the upwork-claude-test folder) if you want.
